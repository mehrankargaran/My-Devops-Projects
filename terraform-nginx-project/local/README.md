# Local Nginx Installation

This folder contains files for **installing Nginx on the local VM**.

### Files:

- `main.tf` → Terraform script to install and configure Nginx  
- `install_nginx.sh` → Bash script generated by Terraform

### Running Terraform:

```bash
cd local
terraform init
terraform apply -auto-approve
Verifying Installation (Optional):
bash
Copy code
systemctl status nginx
curl http://localhost:8080
The custom Kargaran HTML page should appear.
